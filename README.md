## ゲームの概要
- ゲームタイトル：FaceStrike
- 特徴：顔を使った体感的操作
- プレイ時間：30分
- 開発環境：Unity
- 使用技術：Figma,Git,Mediapipe（顔認識を行うためのアセット）

## ゲームの起動方法
1. ファイル（FaceStrike）をダウンロードする。
2. ファイルを展開する。
3. InteractiveSystem.exeをダブルクリックでゲームが起動します。

## 操作方法
- 顔を動かすことでプレイヤーオブジェクトが移動します。
- 顔を縦にうなずくように振ると弾が発射でき、弾を打つことで敵を倒すことができます。

## 動作環境
- Windows 10/11
